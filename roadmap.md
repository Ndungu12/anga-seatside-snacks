# Roadmap

Frontend-only prototype: mock data, simulated payments and SMS, no backend.

- [x] Premium dark design system with official ANGA logo, blue #0757B5 and yellow #FFD900, Manrope + Inter
- [x] Landing hero, visual cinema cards, Now Showing posters, seat confirmation, e-ticket matching the printed ticket
- [x] Photo catalogue (27 items, 6 categories), search, recommendations, combo suggestion, product options, stock
- [x] Basket with options and seat delivery line, checkout, simulated M-Pesa (success, fail, cancel, processing, timeout, duplicate callback)
- [x] Confirmation and four-step tracking driven by the kitchen, not timers
- [x] Flow 1 admission SMS (validate, send, resend invalidates old link), Flow 2A seat QR, Flow 2B cinema/seat and booking reference
- [x] Campaign pages (cinema screen, Instagram) with utm attribution; M-Pesa Mini App simulation
- [x] Operations console: overview metrics, New/Preparing/Ready/Delivered board, fulfilment, notifications, settings, search
- [x] Admissions workstation and SMS outbox; seat QR signage with real scannable QR, print and SVG download
- [x] /demo presentation: journeys, phone, split view with cashier dashboard, control panel, reset
- [ ] Real integrations (needs a backend): M-Pesa Daraja, SMS gateway, admissions app, ticketing data
